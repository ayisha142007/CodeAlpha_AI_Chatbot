# CodeAlpha - AI Chatbot

## Project Overview

This project demonstrates a simple retrieval-based chatbot developed as part of the CodeAlpha Cloud Computing Internship.

The chatbot is designed to provide instant responses to predefined user input patterns and handle unknown queries with an appropriate fallback response.

## Key Features

* Predefined input patterns
* Instant chatbot responses
* Interactive user conversation
* Unknown input handling
* Chatbot testing
* Accuracy and user engagement testing

## Chatbot Type

**Retrieval-Based Chatbot**

The chatbot retrieves predefined responses based on the user's input.

## Technologies Used

* Python
* Google Colab

## Project Modules

1. Chatbot Initialization
2. Predefined Input Patterns

4. Interactive Chatbot

## How It Works

The chatbot stores predefined user inputs and corresponding responses.

When a user enters a query:

1. The input is converted to lowercase.
2. The chatbot checks whether the input matches a predefined pattern.
3. If a matching pattern is found, the corresponding response is displayed.
4. If no match is found, the chatbot displays a fallback response.
5. The conversation continues until the user enters `bye`.

## Example Queries

The chatbot can respond to inputs such as:

* `hello`
* `hi`
* `how are you`
* `what is cloud computing`
* `what is python`
* `thank you`
* `bye`

## Testing

The chatbot was tested using different types of inputs, including:

* Greeting messages
* Cloud Computing questions
* Python-related questions
* Thank-you messages
* Goodbye messages
* Unknown questions

## Output

The chatbot provides an appropriate predefined response for recognized inputs and a fallback message for unknown questions.

This project demonstrates the development of a simple retrieval-based chatbot using Python. It provides instant responses to predefined user queries and demonstrates basic chatbot interaction and testing.
